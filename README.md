# FT7

A calm trading desk for Flattrade, for Mac and Windows: your account, live markets, OpenBB research and an AI
assistant in one window. FT7 prepares orders; only your click sends one.

**Download and guide: https://www.vatsalgoyal.com/ft7**

This repository holds FT7's downloads only (see [Releases](https://github.com/masterunix/ft7/releases)):

- `FT7.dmg`: Macs with Apple silicon (M1 or later). Open it and drag FT7 to Applications.
- `FT7-Setup-<version>.exe`: Windows 10 and 11, 64-bit. Open it, accept the terms, click Install.

FT7 checks this repository for new versions and updates itself. FT7 isn't made by or affiliated with Flattrade.
